# sistema-de-ventas-

descripción:

Sistema web desarrollado con HTML5, CSS3 y JavaScript para administrar productos y ventas. El proyecto utiliza DOM para la interacción dinámica con la interfaz y LocalStorage para almacenar la información sin necesidad de una base de datos

tecnologías utilizadas:

HTML5
CSS3
JavaScript
LocalStorage

Instrucción de uso:

se descarga el repositorio y luego de abrir el index.html se da comenzar y luego aparece el registro donde las personar puede registrar sus productos con su nombre la cantidad que tiene y el precio y luego en la parte de abajo consultar los productos registrados, la cantidad disponible y el valor total de los productos
