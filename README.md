# sistema-de-ventas-

descripción:
Sistema web desarrollado con HTML5, CSS3 y JavaScript para administrar productos y ventas. El proyecto utiliza DOM para la interacción dinámica con la interfaz y LocalStorage para almacenar la información sin necesidad de una base de datos

tecnologías utilizadas:
HTML5
CSS3
JavaScript
DOM
LocalStorage
